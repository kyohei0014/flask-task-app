# Task Management App

Flask + PostgreSQL を使用して開発したタスク管理Webアプリです。
ユーザーごとにタスクを管理でき、期限管理・検索・並び替えなどの機能を実装しています。

日常的なタスク管理を想定し、
「タスクの整理」「期限の把握」「進捗の可視化」を行えるアプリとして開発しました。

## 主な機能

## 技術選定理由

Pythonを学習する中でWebアプリケーションの仕組みを理解するため、
軽量でシンプルなWebフレームワークであるFlaskを採用しました。

Flaskはルーティングやテンプレート処理などWebアプリの基本構造を理解しやすく、
バックエンドの基礎を学ぶ目的に適していると考えました。

データベースには実務でも広く利用されているPostgreSQLを使用し、
クラウド環境へのデプロイを想定した構成にしています。

---

## 工夫した点

* ユーザーごとにタスクを管理できるよう認証機能を実装
* 期限切れタスクを赤表示することで視覚的に分かりやすく改善
* タスク検索と並び替え機能を追加し、タスク管理の利便性を向上

---

## 開発で苦労した点

### Renderでのデプロイ

ローカル環境ではSQLiteを使用していましたが、
クラウド環境での運用を想定しPostgreSQLへ変更しました。

Renderでのデプロイ時には

* 環境変数の設定
* データベース接続設定
* requirements.txtの整理

などを行い、オンライン上でアプリが動作するように構成を調整しました。

---

### UIのレイアウト調整

タスク一覧画面では

* チェックボックス
* タスク内容
* 編集 / 削除ボタン

の位置関係を調整し、視認性と操作性を改善しました。

HTMLテンプレートとCSSを調整しながら
「タスク管理が直感的に行えるUI」を意識してレイアウトを設計しました。
