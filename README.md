# Task Management App

Flask + PostgreSQL を使用して開発したタスク管理Webアプリです。  
ユーザーごとにタスクを管理でき、期限管理・検索・並び替えなどの機能を実装しています。

日常的なタスク管理を想定し、  
「期限の把握」「タスクの整理」「進捗の可視化」を簡単に行えることを目的として作成しました。

---

## デモ

https://flask-task-app-1.onrender.com/

## 主な機能

### 認証機能
- ユーザー登録
- ログイン / ログアウト

### タスク管理
- タスク追加
- タスク編集
- タスク削除
- タスク完了 / 未完了切り替え

### タスク管理補助機能
- 期限設定
- 期限切れタスクの赤表示
- タスク検索
- タスク並び替え

## 技術選定理由

Pythonを学習する中で、Webアプリケーションの仕組みを理解するために  
軽量なWebフレームワークであるFlaskを採用しました。

Flaskはルーティングやテンプレート処理などWebアプリの基本構造を理解しやすく、  
バックエンドの基礎を学ぶ目的に適していると考えました。

データベースには実務でもよく利用されるPostgreSQLを使用し、  
デプロイ環境でも利用できる構成にしました。

---

## 工夫した点

- ユーザーごとにタスクを管理できるよう認証機能を実装
- 期限切れタスクを赤表示することで視覚的に分かりやすく改善
- タスク検索と並び替え機能を実装し、実用性を向上
- デプロイ環境としてRenderを使用し、実際に動作するアプリとして公開
