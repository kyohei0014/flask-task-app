# Task Management App

Flask + PostgreSQLで作成したタスク管理アプリです。  
ユーザーごとにタスクを管理できるシンプルなWebアプリです。

## デモ

https://flask-task-app-1.onrender.com/

## 機能

・ユーザー登録  
・ログイン / ログアウト  
・タスク追加  
・タスク編集  
・タスク削除  
・タスク完了 / 未完了切り替え  
・期限設定  
・期限切れタスク表示（赤表示）  
・タスク検索  
・タスク並び替え  

## 使用技術

Backend  
- Python  
- Flask  

Database  
- PostgreSQL  

Frontend  
- HTML  
- CSS  
- Jinja2  

Deploy  
- Render  

## 工夫した点

・ユーザーごとにタスクを分離する認証機能を実装  
・期限切れタスクを視覚的に分かりやすくするため赤表示  
・検索機能と並び替え機能を追加してタスク管理の利便性を向上
